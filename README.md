# Task Manager / Užduočių tvarkyklė

## About

This is a simple Python console application for managing tasks.
It lets you organize tasks and keeps them saved between uses.

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Save and load tasks from JSON
- Set task priority
- Search tasks
- Filter tasks by status

## Requirements

- Python 3
- No external packages are required

## How to run

1. Clone or download the repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

Tasks are saved automatically in `tasks.json`.

### Tests

Run the tests with:

```bash
python -m unittest
```

The tests check the main task-management functions.
